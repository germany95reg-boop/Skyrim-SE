# Skyrim SE Mobile v2.52 — проверка рендеринга и выпуск

Базовая ревизия: `129989842f073931aec0babca0ac89875376111a` (v2.51).
Статус: разработка начата; перечисленные ниже проверки **не считаются пройденными**, пока нет артефактов и результатов.

## 1. Аппаратная проверка белой геометрии
- Установить APK v2.51 поверх v2.50 без очистки данных.
- На одном и том же NIF моста Вайтрана сохранить кадр PixelCopy и полный диагностический отчёт.
- Сверить `SSE RGBA v2.51`, `BSTriShape #100` (4061 треугольник), общую геометрию (5879), DDS (5/5).
- Зафиксировать различие «исходные почти белые RGB» vs «выбеливание шейдером». Без кадра с телефона нельзя объявлять проблему устранённой.

## 2. Материалы и освещение
- Не подменять vertex tint полноценным diffuse/PBR.
- Проверить, что UV-less material slot -1 обрабатывается отдельно, а UV + DDS слоты не меняются.
- Проверить геометрические нормали, двустороннее диагностическое освещение, альфу, NaN/Inf и вырожденные грани.
- Любые изменения шейдера сопроводить эталонными тестами и сравнением PixelCopy.

## 3. Графические артефакты
- Составить перечень по кадрам: белые/серые поверхности, неверные UV, швы, обратные грани, мерцание, отсутствующие DDS.
- Каждую проблему связывать с NIF block ID, material slot, flags, DDS path и конкретной причиной; не маскировать отсутствующие данные вымышленными текстурами.

## 4. Регрессионные проверки
- JVM unit tests: NIF SSE RGBA, material slots, tint, геометрия, повреждённые данные.
- Android instrumentation / Vulkan: 30/60/∞ FPS, PixelCopy, отчёт токена сеанса, возврат из Activity.
- Проверить чтение Skyrim.esm/BSA/NIF/DDS только на чтение и отсутствие потерь при ошибках.
- Записывать команды тестов, результат PASS/FAIL и SHA сборки; отсутствие тестового окружения не считать PASS.

## 5. APK
- Собирать ARM64 только после успешных проверок.
- Сохранить applicationId и существующую подпись для установки поверх v2.51.
- Проверить установку без удаления приложения, запуск, доступ к игровым файлам, тест GPU.
- Публиковать APK с контрольной суммой SHA-256 и ссылкой на конкретный CI run / Release.
- Не маркировать v2.52 как готовую, пока нет подтверждённого APK и аппаратной проверки.

## Критерий завершения
Выпуск v2.52 возможен после подтверждённой сборки, тестов, сравнения скриншотов и отсутствия регрессий DDS/геометрии. Данный документ — план и протокол проверки, а не отчёт об успешной реализации.
