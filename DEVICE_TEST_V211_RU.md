# Skyrim SE Mobile v2.11 — проверка DDS каждой части NIF

Только действия внутри приложения, без шагов установки APK.

1. Открой **Настройки → Ресурсы Skyrim SE → Каталог BSA v105**. Сохранённые BSA и `Data` должны восстановиться автоматически.
2. Выбери `lureargonian01.nif` (или оставь автоматически восстановленную модель). Нажми **«Связи материалов частей NIF · v2.11»**. Должна быть цепочка `BSTriShape #5 → BSLightingShaderProperty #6 → BSShaderTextureSet #7` и две известные DDS.
3. Нажми **новую кнопку «Найти DDS каждой части NIF · v2.11»**. Она сама заново считывает связи и использует сохранённую `Data`, без дополнительных кнопок «Пути текстур NIF».
4. Дождись завершения чтения каталогов BSA. В отчёте появится раздел **«DDS по частям NIF · v2.11»**. Для блока #5 должны быть указаны `LureArgonian.dds` и `LureArgonian_n.dds`, если они присутствуют в проверенных архивах.
5. Нажми **«Недавние модели NIF»** и выбери `fishinggear_cluster01.nif`. Нажми **«Найти DDS каждой части NIF»**. Отчёт должен перечислить каждую поддерживаемую BSTriShape и status каждого её diffuse/normal DDS, включая пропущенные или неподдерживаемые связи.
6. Убедись, что модель всё ещё открывается через **«Показать все части NIF в Vulkan · v2.11»** с прежним FPS. В составном режиме DDS пока отключены намеренно.
7. Для проверки старого текстурированного режима выбери `lureargonian01.nif`, нажми **«Пути текстур NIF» → «Найти DDS в папке Data» → «Показать NIF с DDS в Vulkan»**. DDS и нормали должны работать как в v2.10.1.

**Пришли:** отчёт «DDS по частям NIF» для `fishinggear_cluster01.nif`, скриншот составной модели и FPS; отдельно подтвердить, нашлись ли две текстуры приманки. Этого достаточно для разработки настоящего многоматериального Vulkan.

Поиск по индексам не утверждает, что не найденных текстур физически нет: DDS могут лежать в другом BSA или отдельными файлами. Приложение ничего не меняет в Data.
