# Skyrim SE Mobile v1.9 — новая adaptive icon + DDS preview

* Новая иконка из предоставленного пользователем оригинала 114962.png. Новый Android 8+ adaptive icon использует полное изображение в фоне без вторичного скругления и тёмных полос. Также сгенерированы обычные launcher PNG.
* Сохраняются applicationId dev.skyrimsemobile.launcher и постоянная подпись тестового APK; versionCode 19 — обновление поверх v1.8 без удаления приложения.
* Новый декодер первого mip-уровня BC1/DXT1 и BC3/DXT5 для **изображений DDS**, а не пока для текстурирования Vulkan.
* До 4 предпросмотров за запуск; чтение только выбранных записей из BSA через SAF, без изменения архива.
* Работающий Vulkan режим «Каркас» / «Поверхность» не изменён.
* Все оригинальные игровые файлы только для чтения. Порт SkyrimSE.exe пока не готов.

## Проверка на телефоне

1. Установить v1.9 поверх v1.8. При такой же подписи и versionCode 19 переустановка не требуется.
2. Проверить значок на рабочем столе Samsung: изображение должно занимать всю маску OneUI, без белых полей и полос.
3. Настройки → Ресурсы Skyrim SE → Каталог BSA → `ccBGSSSE001-Fish.bsa` → поиск `lureargonian01.nif`.
4. Нажать «Пути текстур», затем «Найти DDS в папке Data», выбрать Data.
5. Нажать «Показать текстуры DDS · BC1/BC3 · v1.9»: две текстуры появятся в отдельном окне (диффузная и карта нормалей).
6. Проверить прежние режимы 3D «Каркас» / «Поверхность» без изменений.

DDS-предпросмотр декодирует только первый mip и не экспортирует текстуру. Оригинальные файлы BSA не изменяются. Для полного текстурирования модели через Vulkan потребуется отдельный этап с UV и sampler.
