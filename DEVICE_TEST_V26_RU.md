# Skyrim SE Mobile v2.6 — подробная проверка внутри приложения

Установка APK здесь не описана.

1. Открой **Настройки → Ресурсы Skyrim SE · BSA / NIF (чтение) → Каталог BSA v105 · выбор и проверка NIF**.
2. Нажми **«Выбрать архив BSA»**, выбери `ccBGSSSE001-Fish.bsa`. В строке поиска введи `lureargonian01.nif`.
3. Нажми **«Части NIF · выбрать BSTriShape · v2.6»**. Должно появиться окно со списком геометрических частей. Для этой приманки ожидается **одна** часть; у неё будет номер блока NIF, число вершин и треугольников.
4. Нажми на эту часть в списке. Откроется 3D-просмотрщик с геометрией. **Текстуры здесь намеренно не подключены**: новый режим проверяет только отдельные части NIF.
5. Нажми **«Поверхность»**. Объект должен закраситься однотонно. Проверь **«Крупнее»**, **«Вписать»**, виды **«Спереди»** и **«Сбоку»**, FPS. **«DDS» и «Нормали» в этом режиме неактивны — это нормально**.
6. Нажми **«← Назад»** и вернись в каталог. Для проверки прежнего текстурирования нажми **«Пути текстур NIF · v2.6» → «Найти DDS в папке Data · v2.6»**, выбери папку Data, затем **«Показать NIF с DDS в Vulkan · v2.6»**.
7. В обычном режиме убедись, что **DDS**, **Нормали**, **Свет**, **Рельеф**, **Блик** и компактная панель работают как раньше.
8. Дополнительно можешь выбрать **другую NIF-модель** из предоставленных тобой BSA (не обязательно Fish), где больше одной BSTriShape. Нажми **«Части NIF»**. Если список показывает несколько пунктов, проверь открытие каждого без вылетов; неподдерживаемые должны иметь объяснение.

**Что прислать:** скриншот списка частей NIF, скриншот одной части в Vulkan, а также сообщение, что старый режим DDS по-прежнему работает. Если получишь ошибку, нажми «Скопировать список и отчёт» и пришли текст.

Ограничение: отображение нескольких частей **вместе** и автоматическое назначение материалов по отдельным геометрическим блокам появятся на последующих этапах. Ничего из архива игры не изменяется.
