# Skyrim SE Mobile v2.10 — проверка связей материалов

Без инструкций по установке APK.

1. Открой **Настройки → Ресурсы Skyrim SE → Каталог BSA v105**. BSA и последняя NIF должны восстановиться автоматически, как в v2.9.
2. Выбери **`fishinggear_cluster01.nif`** через «Недавние модели NIF» или поиск в `ccBGSSSE001-Fish.bsa`.
3. Нажми **«Части NIF · выбрать BSTriShape · v2.10»** и посмотри список частей. Закрой его.
4. Нажми новую кнопку **«Связи материалов частей NIF · v2.10»**. В отчёте ожидается перечисление цепочек `BSTriShape # → BSLightingShaderProperty # → BSShaderTextureSet #` с путями DDS `[0]` и `[1]`.
5. Если часть помечена «Не разрешено», пришли текст отчёта. Это означает неподдержанную или отсутствующую ссылку, не повреждение игры.
6. Нажми **«Показать все части NIF в Vulkan · v2.10»** и проверь модель без DDS, FPS, «Крупнее» и «Вписать».
7. Выбери `lureargonian01.nif`, проверь её новый отчёт. Затем нажми **«Пути текстур NIF» → «Найти DDS в папке Data» → «Показать NIF с DDS в Vulkan»**. Старый режим с текстурой и нормалями должен работать без изменений.

**Пришли:** отчёт связей `fishinggear_cluster01.nif`, число связей с материалами, FPS и результат проверки `lureargonian01.nif` с DDS.

Это подготовка к многоматериальному Vulkan: на данном этапе составная геометрия ещё не получает несколько DDS одновременно.
