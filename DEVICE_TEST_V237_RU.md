# Skyrim SE Mobile v2.37 — автоматизация анализа Skyrim одной кнопкой

Вместо отдельных выборов ESM, BSA, NIF и разделов WRLD/CELL появился простой основной экран.

## Рабочий процесс

1. Один раз нажать **«Выбрать папку Skyrim»** и подтвердить Android-доступ к папке игры с Data (можно выбрать саму Data).
2. Сразу после выбора приложение запускает анализ автоматически; позже достаточно кнопки **«Проверить Skyrim автоматически»** без повторного выбора.
3. Самостоятельно обнаруживает Data и Skyrim.esm в разрешённой папке, выбирает WRLD, читает REFR/ACHR (NAME/DATA), затем базовые FormID, MODL/NIF, ищет нужные ресурсы среди BSA и проверяет до трёх NIF с LZ4 в памяти.
4. Один текстовый отчёт, кнопка «Скопировать отчёт». Старые ручные инструменты есть в **«Для разработчика»**, но по умолчанию скрыты.
5. Если Android отозвал доступ, попросит снова выбрать папку. Приложение не сможет автоматически залезть в неподтверждённые каталоги вне разрешённой области SAF.

## Ограничения

- Только те каталоги BSA и ESM, к которым Android действительно предоставил разрешение. Внешние папки, не являющиеся потомками разрешённой, не читаются.
- Первые 1000 заголовков вложенных WRLD; первые 8 размещений; поисковые BSA до 48; проверка максимум 3 NIF. Это **диагностический образец**, не полный мир Skyrim.
- Файлы не изменяются; модели не размещаются на 3D-сцене и SkyrimSE.exe не запускается.
- Сохранены прежние package id и тестовый ключ, APK v2.37.0 (versionCode 60) должен устанавливаться поверх v2.36 без удаления.
- Продолжительный FPS-тест пока не добавлен.
