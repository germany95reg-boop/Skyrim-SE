# Skyrim SE Mobile v2.15 — автотест прямо на телефоне

Устанавливай APK **поверх v2.14**: Android package name, разработческий сертификат подписи и Android-приложение остаются прежними; **versionCode 38**, **versionName 2.15.0**.

## Один раз настрой доступ к Skyrim

В просмотрщике **BSA / NIF** выбери архив BSA и папку игры **Data** через системный Android-файловый менеджер. Доступ сохранится только если Android предоставил постоянное разрешение на чтение. Если архив и Data уже были выбраны раньше, ничего повторно выбирать не нужно.

## Как выполнить полный тест

1. На главном экране лаунчера нажми **«ЗАПУСТИТЬ ПОЛНЫЙ АВТОТЕСТ НА ТЕЛЕФОНЕ»**. Один тап открывает новый экран и **сразу начинает проверку**.
2. Приложение автоматически проверит ARM64, установленный APK и аппаратный Vulkan-драйвер; прочитает сохранённый BSA v105; найдёт подходящий NIF (сначала последний использованный); проверит BSTriShape → shader → texture set; попытается найти и декодировать diffuse DDS из сохранённой Data; соберёт составную геометрию и атлас.
3. Затем приложение **само откроет свой Vulkan 3D экран** и попытается отрисовать минимум 45 кадров на реальном GPU. Если допустимая NIF готова — проверит её, иначе встроенный куб. После успеха экран автоматически закроется и вернётся к результату. При ошибке или отсутствии кадров остановится через 20 секунд с сообщением.
4. В итоговом отчёте будут строки **PASS / WARN / FAIL / SKIP**, значения разрешения и FPS и причина сбоя. Нажми **«Копировать отчёт»**, вставь его сюда в чат, или **«Поделиться отчётом»**. Самостоятельно лаунчер данные никуда не отправляет.

Кнопка автотеста есть и в просмотрщике BSA. Кнопка «Запустить полный автотест» на экране тестов повторяет весь прогон.

## Ограничения и безопасность

- Не используется эмулятор, Wine или Windows-среда: тесты внутри APK выполняются именно Android-приложением на физическом телефоне.
- Используются только **ранее выданные SAF-разрешения**. Папка Data обходится на одном уровне: максимум 4096 объектов и 48 BSA. Использование памяти ограничено: до 12 уникальных DDS и максимум 8 млн пикселей исходных DDS.
- Сами архивы Skyrim не изменяются. Игра и скрипты не запускаются. Полный путь к личной папке SAF, URI и содержимое файлов не выгружаются в отчёт.
- Если BSA/NIF отсутствуют, автотест **не зависнет**: покажет SKIP и проверит встроенную Vulkan-сцену.
- FPS измеряется на коротком диагностическом окне. Он не равен FPS в самой игре. Факт рендера кадров не гарантирует правильность каждого пикселя.
- GitHub CI проверки NIF/BSA/DDS и сборка подписанного ARM64 APK выполняются; **эмуляторный этап удалён из обязательного CI**.

Цель — **один APK после большого этапа → одна кнопка на твоём смартфоне → один текстовый отчёт**. Не требовать у пользователя проверки каждой мелкой кнопки.
