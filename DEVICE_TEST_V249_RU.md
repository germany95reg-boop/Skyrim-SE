# Skyrim SE Mobile v2.49 — диагностический прогон на телефоне

1. Установи v2.49 поверх v2.48 без удаления приложения. На закрытой странице GitHub Release открой Assets и скачай ARM64 APK.
2. Открой «Ресурсы Skyrim SE». Приложение автоматически проверит Skyrim/Data, откроет локальную 3D-сцену и выполнит три этапа FPS, PixelCopy и отчёт.
3. Нажми «Скопировать отчёт». В конце после `DDS: 5 / 5` появится новый раздел **Аудит покрытий BSTriShape v2.49**.
4. Пришли этот раздел от заголовка до последней строки. Он должен перечислить BSTriShape #, число треугольников и причины: `НЕТ UV`, `НЕТ ДИФФУЗНОЙ СВЯЗИ`, `DDS НЕ ДЕКОДИРОВАНА` или `DDS ОК`.
5. Приложи скриншот 3D-изображения, если оно изменилось, и итог PASS/WARN/FAIL.

**Ожидаемая ситуация:** в v2.48 на мосту подтверждено лишь 1718/5879 текстурированных треугольников. v2.49 не подделывает отсутствующие материалы и сам по себе не гарантирует улучшение картинки. Новый отчёт позволит определить, какой из двух компонентов — декодер геометрии/UV или таблица шейдеров NIF — нужно исправлять дальше.

Проверки выполняются над ограниченной выборкой и не изменяют исходные файлы Skyrim. Полная игровая сцена пока не поддерживается.
