# Skyrim SE Mobile v2.10.1 — проверка ошибки блока #6

Действия только внутри приложения.

1. Открой «Настройки → Ресурсы Skyrim SE → Каталог BSA v105». Дождись восстановления `ccBGSSSE001-Fish.bsa`.
2. Выбери `lureargonian01.nif` через «Недавние модели NIF» или поиск.
3. Нажми **«Связи материалов частей NIF · v2.10.1»**. Ошибка «Некорректное количество extra-data ссылок в #6» больше не должна появляться.
4. Если блок #6 использует стандартную структуру SSE, в отчёте появится цепочка `BSTriShape #5 → BSLightingShaderProperty #6 → BSShaderTextureSet #...` и фактические пути DDS [0] и [1]. Не угадывай индексы: пришли отчёт целиком.
5. Если указано «Не разрешено», пришли текст — тогда разберём следующую особенность именно этого NIF.
6. Нажми «Показать NIF с DDS в Vulkan · v2.10.1» и проверь обычные DDS, карту нормалей, камеру и FPS.
7. Дополнительно проверь отчёт «Связи материалов частей NIF» для `fishinggear_cluster01.nif`.

Новая функция по-прежнему диагностическая: многочастная модель в Vulkan пока без собственных DDS. Файлы игры не изменяются.
