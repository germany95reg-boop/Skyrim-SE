# Skyrim SE Mobile v2.24 — больше места для 3D-модели при автотесте

## Реальные результаты v2.23

Samsung SM-S948B, Android 17, Adreno 840 / Vulkan 1.4.295: **PASS 22 · WARN 0 · FAIL 0 · SKIP 0**, FPS 29.9 / 59.9 / 120.1. Модель `fishinggear_cluster01.nif` (3349 треугольников, normal-safe, DDS alpha) отображалась в PixelCopy как **838/49152 пикселей, 1.70% кадра, область 48×60 пикселей**. Предыдущая v2.22 давала 565/49152 (1.15%) и 43×49. Новая камера с `geometry-yaw-sweep` действительно увеличила модель примерно на 48% по количеству пикселей.

Однако камера сообщила **только 35% свободной высоты дисплея**, потому что многострочный диагностический статус и обычные кнопки 3D-просмотра занимали остальное пространство.

## Что изменено в v2.24

**Только в автоматическом GPU-тесте** вместо большой панели интерактивных кнопок показывается одна маленькая нижняя строка: «Автотест · этап N/3 · FPS … · … кадров». Названия трёх FPS-этапов и текущее количество кадров видны, пока на Vulkan SurfaceView выводится проверяемая NIF.

**В обычном 3D-просмотрщике никакие кнопки не скрываются**: остаются камера, «Вписать», «Крупнее», DDS, normal-map, освещение и выбор OBJ.

Реальное авто-вписывание вычисляет свободное пространство по **высоте компактной панели**, а не по скрытым кнопкам. В отчёте строка **«Авто-вписывание камеры NIF»** дополнительно указывает режим `компактный HUD` и фактическую высоту нижней строки в пикселях.

Это позволяет приближать модель **без обрезки геометрии** по проверенным в Java поворотам; фактический результат на телефоне нужно подтвердить PixelCopy. Также автотест больше не выполняет несущественные периодические записи статуса в SharedPreferences каждые 700 мс. Обычный просмотр сохраняет своё поведение.

## Установка и проверка

Установи подписанный **v2.24.0** (Android versionCode **47**) **поверх v2.23.0**, не удаляя приложение. Сохранены package ID, подпись, данные и файловые разрешения.

Запусти полный автотест, скопируй отчёт. Особенно нужны две строки:

- **«Авто-вписывание камеры NIF»** — новая доля свободной высоты дисплея, дистанция, «компактный HUD».
- **«Изображение Vulkan PixelCopy»** — сравним её с прежними **838 пикселями, 1.70%, областью 48×60**.

Проверки NIF, BSA, diffuse+normal DDS, alpha-mask, нормалей на GPU и 30/60/∞ FPS сохранены. Само изображение PixelCopy не сохраняется и не отправляется, игровые файлы остаются без изменений.

Этот инструмент проверяет данные Skyrim и собственный Vulkan 3D-просмотрщик. **Это не запуск SkyrimSE.exe и не полноценная игровая производительность.**
