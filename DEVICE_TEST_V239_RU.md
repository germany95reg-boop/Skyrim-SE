# Skyrim SE Mobile v2.39 — первый реальный 3D-предпросмотр размещённого объекта

По реальному отчёту Android v2.38 подтверждены 23 проверенных BSA, 3/4 пути MODL, 3/3 LZ4 NIF и 16/16 распознанных статических частей.

**Добавлено:** при автоматической проверке `Skyrim.esm` приложение ищет прямую связь `REFR → NAME → базовая запись MODL → NIF в BSA`. Для первого видимого статического объекта (маркеры и ACHR исключаются) оно строит ограниченные буферы линий/треугольников с локальными BSTriShape, иерархией NiNode, мировыми координатами и поворотом REFR, затем преобразует модель в диапазон существующего Vulkan-просмотрщика. Если найденная модель подходит, появляется кнопка **«Просмотреть найденный объект в 3D»**. Повторно выбирать NIF/BSA не требуется.

Новый парсер `XSCL` (масштаб REFR) использует значение 1.0 при отсутствии записи, проверяет конечные числа и диапазон 0.01–100. Порядок вращений Rz*Ry*Rx реализован как **предварительное** отображение; требуется сверка с движком Creation Engine. Используется мировая позиция, но для читаемого предпросмотра один объект центрируется на экране; это не показ всей карты в глобальном масштабе. Текстуры DDS пока не подключены к этой автоматической сцене.

Технические кнопки остаются в скрытом разделе «Для разработчика». Прежняя автоматическая проверка NIF сохраняется. Сборка v2.39.0, versionCode 62, прежний package ID и сертификат тестовой подписи. Не является полноценным портом SkyrimSE.exe.

## Проверка

Установить APK поверх v2.38; открыть ресурсы Skyrim → «Проверить Skyrim автоматически». После завершения найти строку «3D-предпросмотр подготовлен» и нажать «Просмотреть найденный объект в 3D». Убедиться, что вращается **настоящая статическая модель** из `Skyrim - Meshes0.bsa` без текстур и что в отчёте указан связанный FormID. Прислать отчёт и скриншот. Никакие игровые файлы не изменяются.
