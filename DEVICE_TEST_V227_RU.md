# Skyrim SE Mobile v2.27 — чтение ESM/ESP/ESL

Следующий шаг после успешного теста v2.26 (22 PASS): чтение начальной TES4-записи плагинов. Читаются HEDR (версия, число записей, ObjectID), CNAM (автор), SNAM (описание), зависимости MAST и флаги master/ESL/localized.

## Проверка на телефоне

1. Установи APK 2.27.0 (versionCode 50) поверх 2.26.0, не удаляя установленное приложение.
2. Открой «Ресурсы Skyrim SE» и нажми «Проверить ESM / ESP / ESL (заголовок TES4)».
3. Выбери файл Data/Skyrim.esm из собственной копии игры или другой .esm/.esp/.esl.
4. Посмотри HEDR и список MAST; при ошибке чтения должен отображаться текст вместо вылета.
5. Короткий аппаратный автотест Vulkan остаётся доступным. Продолжительный стресс-тест намеренно отложен.

## Ограничения

Читается только первый TES4 record размером не более 4 МиБ. CELL/WRLD/REFR, FormID, содержимое игровых записей, скрипты, NPC, физика, анимация, игровой цикл и запуск SkyrimSE.exe ещё не реализованы. Игровые файлы не модифицируются и не включаются в APK.
