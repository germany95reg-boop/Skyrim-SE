# Проверка v2.43 на смартфоне

1. В закрытом GitHub-репозитории открыть **Releases** и скачать `Skyrim-SE-Mobile-v2.43.0-ARM64.apk` из тестового prerelease. GitHub Actions больше не использует Artifacts: прежняя квота не препятствует загрузке APK как Release asset.
2. Установить APK поверх v2.42, **не удаляя** приложение. Версия должна быть 2.43.0 (код 66). Пакет `dev.skyrimsemobile.launcher` и тестовая подпись сохранены.
3. Выбрать папку Skyrim/Data один раз, затем нажать **«Проверить Skyrim автоматически»**. Если доступны видимые NIF/REFR, открыть локальный 3D-предпросмотр. Дождаться появления геометрии, затем вернуться.
4. В автоматическом отчёте проверить секцию **3D-предпросмотр Vulkan** и строку **PixelCopy**. Статус «обнаружен рисунок» означает только отличие части пикселей Vulkan-поверхности от ожидаемого цвета очистки, а не корректный игровой рендер. «WARN — не содержит достаточных признаков» может означать пустой кадр, ошибку камеры или очень тонкую модель.
5. Скопировать отчёт и сделать скриншот именно 3D-экрана, если картинка неверна. PixelCopy-данные не содержат изображение: оно хранится только кратковременно в памяти.
6. Если релиз на GitHub не появился, проверить журнал Actions: публикация требует `contents: write` для сборочного задания и доступного GitHub Releases. Не публиковать этот debug APK как производственный релиз.

**Ограничения:** автоматическая сцена — небольшая ограниченная выборка реальных объектов, не полный мир Skyrim SE. Нет NPC, ландшафта, игрового движка и полного наборa материалов. Проверка на реальном устройстве обязательна.
