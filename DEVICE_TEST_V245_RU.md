# Skyrim SE Mobile v2.45 — автоматическая проверка локальной сцены

1. Установи v2.45 поверх v2.44 (сохраняется исходная подпись и package ID).
2. Открой экран **Ресурсы Skyrim SE**. Если папка Skyrim/Data была разрешена ранее, проверка запускается **сама при входе**. Если она ещё не выбрана — предоставь Android доступ один раз; сканирование запустится автоматически.
3. Приложение читает Skyrim.esm, подбирает REFR + NIF, получает UV и связанные DDS (если они доступны) и **само открывает найденную локальную сцену**.
4. На реальном Android-телефоне Vulkan показывает саму выбранную модель, включает поверхность, тестирует нативные лимиты 30/60/без ограничения FPS, запрашивает PixelCopy и **автоматически возвращается** в экран ресурсов с подробными строками PASS / WARN / FAIL.
5. Нажми **Скопировать отчёт**; если возникла ошибка, пришли отчёт и скриншот. Для ручного просмотра без автозакрытия остаётся кнопка **Просмотреть локальную сцену в 3D**.

**PASS** требует совпадения имени реальной сцены, конкретного числа треугольников, GPU-кадров, FPS-этапов и признаков изображения. **WARN** означает ограниченное свидетельство, например отсутствующую DDS или незавершённую PixelCopy; **FAIL** — неподтверждённые важные условия, например подмену NIF кубом или пустую поверхность.

Тест не может подтвердить точность цветов/UV/света относительно Skyrim без эталонных игровых кадров. Это диагностический просмотр части реальных файлов игры, а не запуск SkyrimSE.exe или полный тест всего открытого мира. Ограничения сканирования BSA/NIF/DDS из v2.44 сохранены.
