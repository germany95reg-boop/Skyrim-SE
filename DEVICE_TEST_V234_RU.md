# Skyrim SE Mobile v2.34 — автоматический поиск моделей в BSA папки Data

Получен реальный отчёт: Skyrim.esm WRLD — 997 записей выборки, 8 размещений REFR с корректно прочитанными NAME+DATA, 5 из 6 базовых FormID найдены, четыре пути MODL. Проверка Fish.bsa обнаружила 0 совпадений — это закономерно, потому что этот BSA не содержит необходимые модели.

## Добавлено

- Кнопка «Найти MODL во всех BSA папки Data» после чтения WRLD/CELL.
- Пользователь даёт Android доступ к папке `Data` через штатный системный выбор папки; уже сохранённое разрешение переиспользуется.
- Программа последовательно читает **только каталоги BSA v105**, не распаковывает NIF и не изменяет архивы.
- Лимит 48 BSA. При отсутствии разрешений, неполном индексе, ошибках чтения или превышении лимита результат обозначается как неполный/неподтверждённый.
- Для каждого уникального пути MODL показывается архив, где NIF обнаружен; совпадение имён точное и нечувствительное к регистру.
- Старый режим сравнения с одним BSA сохранён.

## Проверка на телефоне

1. Установить v2.34.0 (код 57) поверх v2.33.0.
2. «Настройки → Ресурсы Skyrim SE → Записи WRLD · FormID / базовые модели (образец)», открыть `Data/Skyrim.esm`.
3. Нажать «Найти MODL во всех BSA папки Data». Если приложение попросит доступ к папке, выбрать именно **Data** и подтвердить разрешение.
4. Скопировать отчёт. Ожидаются статусы по архивам, например Skyrim - Meshes*.bsa. Файлы не изменяются.

Это **не порт SkyrimSE.exe**, не отрисовка мира и не полная обработка master/override, BSA payload или NIF.
