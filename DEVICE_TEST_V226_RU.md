# Skyrim SE Mobile v2.26 — исправление ручного просмотра по двум скриншотам

## Реальные результаты v2.25

Устройство Samsung SM-S948B / Android 17 / Adreno 840 подтвердило **22 PASS, 0 WARN, 0 FAIL** для автоматического NIF/BSA/DDS/Vulkan-теста: 2 BSTriShape, 3349 треугольников, Vulkan `normal-safe`, alpha cutouts, PixelCopy ~3.18%, FPS 29.9/59.8/120.2.

Однако два пользовательских скриншота с ручным просмотром **v2.25** показали отдельную, не покрываемую авточеком проблему: текст и раскрытая панель кнопок практически полностью закрывали Vulkan SurfaceView. В status указано **18% свободного места**, а сама модель видна только в узкой полосе вверху. Кроме того, открыт режим **только одной BSTriShape (#5, 2887 треугольников)**; это не полная NIF с 3349 треугольниками.

## Исправления v2.26

1. **Восстановлен просторный ручной 3D-экран.** Технический отчёт скрыт по умолчанию, на его месте короткая однострочная строка с реальными показателями Vulkan. Полный текст раскрывается кнопкой **«Сведения ▾»**.
2. **Кнопки прокручиваются в нижней панели, ограниченной 38% высоты дисплея** (минимальная поддержка маленьких экранов 180 dp). Даже при раскрытых «Параметрах» поверхность Vulkan остаётся видимой. **«Вписать»** рассчитывает камеру по реальной высоте этой панели, а не по её длинному содержимому.
3. **Заголовок уменьшен до одной строки**. Больше места остаётся изображению, а не тексту. Ручное управление жестами, кнопки вида, FPS, normal-safe, рельеф, свет, альфа-смешивание сохранены.
4. **В каталоге BSA правильный полный просмотр NIF вынесен наверх:** **«1 · Найти DDS каждой части NIF»**, затем **«2 · Открыть ВСЮ NIF с DDS (все части)»**. Старые варианты, открывающие только один BSTriShape, помечены «Диагностика ОДНОЙ части», чтобы их не путали с полноценной моделью.
5. Однокнопочный аппаратный автотест по-прежнему показывает **компактный HUD**, не меняет проверенные режимы 30/60/∞ FPS, PixelCopy и стандартную альфа-маску. Экспериментальный альфа-блендинг выключен по умолчанию.

## Установка и проверка

Подписанный APK **v2.26.0, versionCode 49** устанавливается поверх v2.25 (версия 48). **Не удаляй установленную программу.** Приложение использует тот же Android package ID и сертификат обновления.

Открой **BSA-каталог** → выбери `fishinggear_cluster01.nif` → нажми **1** («Найти DDS каждой части NIF»), затем **2** («Открыть ВСЮ NIF с DDS (все части)»). В ручном Vulkan 3D-просмотрщике проверь:

- модель должна отображаться в большой видимой области, а не в полоске у заголовка;
- «Сведения ▾» раскрывает полный диагностический текст **внутри прокручиваемой панели**, не перекрывая всю модель;
- «Параметры ▾» и экспериментальное «Альфа: Смешивание» по-прежнему доступны с прокруткой;
- в строке «Треугольников» при открытии **всей** NIF должно быть **3349** (а не 2887 одной части). Если число другое, передай скриншот и точный путь NIF.

Потом запусти привычный полный автотест и пришли отчёт. Он отдельно проверит 2 части и 3349 треугольников, нормали DDS, Vulkan PixelCopy и FPS.

**Ограничения:** альфа-смешивание остаётся экспериментальным; нет сортировки прозрачных треугольников. Это просмотрщик NIF, а не запуск `SkyrimSE.exe`. Исходные BSA и файлы Skyrim не изменяются, снимки и отчёты не отправляются автоматически.
