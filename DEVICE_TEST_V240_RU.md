# Skyrim SE Mobile v2.40 — проверка настоящего Vulkan-отображения

По реальному отчёту v2.39: `StockadeBarricade01Activator` связан с `REFR 0x000B414D` и моделью из `Skyrim - Meshes0.bsa`. Декодировано 12 частей BSTriShape, 3910 треугольников, связаны координаты XYZ и масштаб 1.0. Но реальная отправка кадров Vulkan на телефон пока не подтверждена.

## В v2.40

- Сохраняет прежний экран с одной кнопкой анализа Skyrim и условной кнопкой 3D.
- При открытии 3D генерирует одноразовый токен; передаёт его в Vulkan-просмотрщик и очищает старые показатели.
- Vulkan-просмотрщик записывает фактические данные `nativeGetStats()`: имя геометрии, количество рёбер, треугольников, число готовых кадров, FPS и размеры поверхности.
- По возвращении из 3D в исходный экран эти данные присоединяются к **единому отчёту**. Счётчики подтверждаются только при точном совпадении названия модели, минимум двух кадрах, ненулевой геометрии и отсутствии ошибки.
- Если 3D экран не запустился, завершился без кадров, сменил модель на встроенный куб либо не подтвердил поверхность — показывает **неподтверждённый** результат, а не ложный успех.
- Нативные счётчики не подтверждают, что изображение отображено правильно: для следующей стадии всё равно нужен скриншот с устройства.

Приложение остаётся демонстрационным просмотрщиком отдельных ресурсов, не игровым движком. Не запускает SkyrimSE.exe. Подпись и пакет остаются прежними; v2.40.0, versionCode 63. Длительный FPS-тест не включён.

## Проверка на устройстве

Установи v2.40 поверх v2.39 без удаления. Нажми «Проверить Skyrim автоматически», после появления кнопки «Просмотреть найденный объект в 3D» открой её, посмотри модель несколько секунд, вернись назад. Нажми «Скопировать отчёт»: в конце появится «3D-предпросмотр Vulkan». Пришли отчёт и скриншот 3D, чтобы проверить достоверность отрисовки.
