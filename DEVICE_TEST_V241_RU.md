# Skyrim SE Mobile v2.41 — ограниченная локальная сцена из нескольких REFR

Последняя успешная версия v2.40 подтверждала запуск компиляции ARM64/Vulkan и проверку фактических GPU-счётчиков после просмотра одного NIF. Версия v2.41 добавляет **группировку нескольких соседних объектов** по координатам реальных REFR из Skyrim.esm.

## Изменения

- Увеличена ограниченная выборка с 8 до 20 размещений (максимум 60 проб чтения), поиск уникальных баз — до 32. Это остаётся частичным примером чтения WRLD, а не полным анализом мира.
- При автоматической проверке читаются до 3 NIF из BSA, как и раньше. Для каждого найденного видимого статического REFR выполняется ограниченная подготовка геометрии NIF; повторные ссылки на тот же NIF используют уже распакованную геометрию в памяти.
- Сборщик сцены объединяет до 8 размещений, удалённых не более чем на 8192 **внутриигровых единиц** от первого доступного объекта. Дальние модели намеренно исключаются, иначе всё становится слишком мелким в одном кадре.
- Для включённых объектов отдельно применяются их NiNode/BSTriShape-трансформации, REFR XYZ, RzRyRx (предварительный порядок), XSCL. **Только после этого** сцена нормализуется общим масштабом, сохраняя относительное положение объектов. Бюджеты 30 тыс. рёбер / 30 тыс. треугольников, максимум 8 экземпляров.
- Сообщение показывает количество объектов в локальной сцене, количество не включённых дальних размещений и ограничений. Кнопка просмотра остаётся одна — **«Просмотреть найденный объект в 3D»**, без дополнительных технических категорий.
- Если среди доступных записей нет соседних видимых объектов, программа покажет один объект. Это корректное ограничение данных, не имитация многопользовательского мира.

## На смартфоне

Установить v2.41.0 (versionCode 64) поверх v2.40.0, запустить единственную автоматическую проверку и открыть 3D-предпросмотр. Скопировать отчёт и, если возможно, сделать скриншот сцены. Исходные BSA/ESM не изменяются. Это не полный SkyrimSE.exe, не ландшафт, не текстуры, не NPC и не игровой рендеринг с оригинальным движком.
