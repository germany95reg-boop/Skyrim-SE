# Skyrim SE Mobile v2.51 — проверка исправления белого моста

1. Установи v2.51 поверх v2.50. GitHub Releases → Assets → `Skyrim-SE-Mobile-v2.51.0-ARM64.apk`.
2. Открой «Ресурсы Skyrim SE», запусти автоматическую проверку и дождись автоматического окончания всех трёх режимов FPS.
3. Сохрани новый скриншот 3D-моста: в диагностическом изображении белые вершины теперь должны иметь геометрические светотеневые градации, хотя **реальный материал без UV всё ещё неизвестен**.
4. Найди в отчёте строку **SSE RGBA v2.51**. Она содержит процент почти белых исходных RGB, средний RGB и число вырожденных треугольников. Это определит, белая ли NIF как маска или ошибка цвета.
5. Проверь, что **DDS: 5 / 5**, `BSTriShape #100` имеет 4061 треугольник и что Vulkan всё ещё отдаёт 5879/5879 треугольников. Пришли скриншот и хвост отчёта с `SSE RGBA v2.51` и `PASS/WARN/FAIL`.

Это диагностический NIF/REFR Vulkan-просмотр, не полноценный Skyrim; никакие исходные игровые файлы не меняются.
