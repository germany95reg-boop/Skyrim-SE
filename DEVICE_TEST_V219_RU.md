# Skyrim SE Mobile v2.19 — точные пары diffuse/normal и обновлённый отчёт

## Основание: реальный тест Adreno 840

Автотест v2.18 на Samsung SM-S948B (Android 17, Vulkan 1.4.295) завершился **PASS 19 · WARN 0 · FAIL 0 · SKIP 0**. Для модели `fishinggear_cluster01.nif` обе части BSTriShape сохранили родительские трансформации, diffuse DDS и normal DDS. Adreno использовал настоящий GPU-пайплайн **normal-safe**, FPS 30/60/без лимита измерены **29.9 / 59.4 / 120.2**.

## Что изменено

1. В v2.18 два объекта с одинаковой diffuse DDS, но разными normal DDS получали один номер материала. Во избежание неправильного рельефа normal-атлас отказывался от такой комбинации. В v2.19 вводится **составной ключ материала (diffuse DDS, normal DDS)** с точной идентичностью исходных декодированных текстур.
2. Для разных пар создаются **отдельные GPU-слоты**, даже когда цветовые DDS совпадают. Нормали больше не подменяются картой другой части. Полностью одинаковые пары продолжают использовать один слот.
3. Если у части отсутствует normal DDS, она получает собственный слот с **нейтральным flat-normal**. Оригинальные UV, количество NIF-треугольников, иерархия NiNode и режимы Vulkan FPS сохранены.
4. Сохраняется прежний **diffuse-only fallback**, если карты нормалей недоступны или превышены ограничения атласа 2048×2048. Это диагностический просмотр, не полноценный графический движок Skyrim.
5. **По просьбе пользователя из конца автотестового отчёта убрана фраза: «Отчёт не отправлялся автоматически; пользователь решает, кому его передать.»** Другой текст отчёта, предупреждения о пределах проверки и правило отсутствия автоматической передачи данных не меняются.

## Как проверить

Установить подписанный `Skyrim-SE-Mobile-v2.19.0.apk` **поверх** v2.18 (без удаления приложения). Открыть **«ЗАПУСТИТЬ ПОЛНЫЙ АВТОТЕСТ НА ТЕЛЕФОНЕ»**; сам тест проверит BSA, NIF, NiNode, DDS, нормали на GPU и 30/60/∞ FPS. Скопировать отчёт.

Также в каталогизаторе BSA есть действие **«Показать ВСЕ части NIF с DDS · v2.19»**. Для моделей с различными парами diffuse/normal нормали должны оставаться привязаны к исходным частям.

Пришли полный отчёт; особенно важны «Normal DDS-атлас», «Normal DDS GPU», «Vulkan DDS-атлас» и три строки FPS.

Подпись и package ID прежние, Android versionCode **42**, versionName **2.19.0**. Исходные игровые файлы не изменяются, эмуляция Windows не используется. Автотест в APK не доказывает пиксельную точность или запуск `SkyrimSE.exe`.
