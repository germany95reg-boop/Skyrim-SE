# Skyrim SE Mobile — v2.0 development

Source of the Android Vulkan preview launcher is now editable in \`mobile/\`.
The original v1.9 snapshot is preserved in the repository.

## Changes
- DDS first-mip CPU preview: BC1, **BC2**, BC3, **BC4 (UNORM)**, **BC5 (UNORM)**,
  plus DX10 RGBA8/BGRA8. BC5 displays X/Y channels as RG for diagnosis.
- Explicit refusal to misdecode BC4/BC5 signed, BC6H/BC7, arrays and truncated records.
- Existing 2048×2048 image, 8 MiB packed / 16 MiB decoded BSA limits retained.
- \`versionCode 20\`, \`versionName 2.0.0\`, same application ID and fixed
  PRIVATE development signing certificate as v1.9 (in-place upgrades).
- Vulkan NIF triangle and wireframe renderers **unchanged**. Textures are
  previewed separately, not UV-mapped to meshes yet.

Build: GitHub Actions → Skyrim SE Mobile Vulkan 3D APK v2.0.
APK artifact: \`Skyrim-SE-Vulkan-3D-v2.0-APK\`.

Testing on device: install APK over v1.9 without removing it. In BSA
catalog open the existing NIF, find DDS in Data and tap
“Показать текстуры DDS · BC1/2/3/4/5 · v2.0”.
Check BC1 diffuse, BC3 normal and any BC5 normal-map records. No BSA writes.

This is an asset preview launcher, not a playable Skyrim Special Edition port.
