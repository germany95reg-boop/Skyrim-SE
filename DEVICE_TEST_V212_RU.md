# Skyrim SE Mobile v2.12 — проверка текстуры отдельной части NIF

1. Установи собранный APK v2.12 поверх v2.11 без удаления приложения.
2. Открой **Настройки → Ресурсы Skyrim SE → Каталог BSA v105**. Последние BSA, NIF и Data должны восстановиться, если Android сохранил доступ.
3. Выбери `lureargonian01.nif` в `ccBGSSSE001-Fish.bsa`. Нажми **«Найти DDS каждой части NIF · v2.11»**. Должна появиться проверенная цепочка `BSTriShape #5 → shader #6 → texture set #7`, а две текстуры — `LureArgonian.dds` и `LureArgonian_n.dds` — как найденные.
4. Нажми **«Показать выбранную часть NIF с её DDS · v2.12»**. Выбери часть `#5`. Должен открыться Vulkan-просмотр только этой части с привязанными DDS. Кнопка «Поверхность» переключает поверхность/каркас, «DDS» — включение/отключение текстур.
5. Проверь свет и нормали: если обе DDS корректно декодируются, доступна кнопка «Нормали». Если нормали не поддержаны, диффузная текстура всё равно должна отображаться.
6. Выбери **`fishinggear_cluster01.nif`**, сначала нажми «Найти DDS каждой части NIF», затем новую кнопку v2.12. Выбирай разные `BSTriShape`: у каждой должен отображаться **её** путь DDS, а не путь первой части. Недоступные части должны объяснять причину.
7. Для регрессии нажми старую **«Показать все части NIF в Vulkan · v2.11»** (геометрия без DDS) и **«Показать NIF с DDS в Vulkan · v2.11»** (старая отдельная модель). Управление камерой, FPS и сохранённые пути не должны измениться.

**Для следующего этапа:** пришли отчёт и скриншоты для двух разных частей `fishinggear_cluster01.nif`, их размеры DDS, работу нормалей и FPS. Это необходимо для перехода к одновременному многоматериальному Vulkan.

**Важно:** v2.12 не реализует многоматериальную составную сцену. Поиск одного частичного индекса BSA не доказывает отсутствие других DDS. Приложение читает игровые файлы без записи.
