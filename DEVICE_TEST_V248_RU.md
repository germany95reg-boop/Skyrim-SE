# Проверка Skyrim SE Mobile v2.48 на Android

1. На странице GitHub Release `skyrim-se-mobile-v2.48.0` разверни **Assets** и установи `Skyrim-SE-Mobile-v2.48.0-ARM64.apk` поверх v2.47, без удаления приложения.
2. Открой «Ресурсы Skyrim SE». Автотест должен снова открыть реальную модель WRDrawBridge01.nif и показать 3 этапа **30 FPS / 60 FPS / без ограничения FPS**. **Не нажимай «Назад» до автоматического закрытия 3D-экрана.**
3. В отчёте найди `DDS:`. Для прежних пяти текстур Whiterun должны появиться записи вида `DDS оптимизирована: ... 2048×2048 → 512×512`. Количество успешно декодированных DDS может стать больше прежнего 1/5; оно зависит от поддерживаемых форматов.
4. Проверь реальный 3D-кадр: исчез ли сплошной серый цвет, есть ли дерево/камень/цепи на мосту. Факт `atlas-safe` сам по себе не доказывает правильность UV.
5. Проверь отдельный сценарий: при следующем запуске нажми **Назад** на этапе 1/3. Приложение должно показать `Автотест не завершён` вместо `Нет подписанного результатом токена`.

Пришли скриншот кадра и хвост отчёта, начиная с `DDS:` и заканчивая `Итог:`.

Границы: сохранён общий предел ~4 млн уменьшенных пикселей, максимально 512 пикселей с каждой DDS по длинной стороне, 15 путей, до 24 BSA в одном проходе. Оригинальные ресурсы игры открываются только на чтение. Это всё ещё просмотр NIF/REFR, а не полный игровой движок Skyrim.
