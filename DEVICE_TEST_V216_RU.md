# Skyrim SE Mobile v2.16 — автоматический тест 30 / 60 / без ограничения FPS

На телефоне, в лаунчере нажми **«ЗАПУСТИТЬ ПОЛНЫЙ АВТОТЕСТ НА ТЕЛЕФОНЕ»**.

Все проверки BSA/NIF/DDS из v2.15 сохранены. В конце приложение **само** открывает Vulkan с выбранной NIF и DDS, затем **без ручных нажатий и без перезапуска сцены** переключает программный лимит:

1. **30 FPS** — прогрев, измерение собственного интервала кадров.
2. **60 FPS** — прогрев, независимый подсчёт кадров и времени.
3. **Без ограничения** (native Vulkan `fpsCap=0`) — измерение кадров без программного ограничения движка.

Каждый этап измеряется независимо по приросту настоящего счётчика кадров и времени на устройстве. Перед началом каждого измерения делается прогрев; смена Vulkan Surface обнуляет незаконченный образец, не завышая FPS. Подтверждается, что native Vulkan действительно получил соответствующий лимит 30, 60 или 0. Если режим не переключился или кадры не появились, в отчёте будет FAIL/WARN, а не ложный PASS.

Пример строк в отчёте (числа FPS лишь для иллюстрации, не прогноз):

- PASS · Vulkan FPS 30: заданный лимит 30 · фактически 29,8 FPS · ... кадров.
- PASS · Vulkan FPS 60: заданный лимит 60 · фактически 59,3 FPS · ... кадров.
- PASS · Vulkan FPS Без ограничения: заданный лимит отключён · фактически 60,0 FPS · ... кадров.

**Важно:** «без ограничения» снимает только программный лимит внутри Vulkan-рендерера. На некоторых устройствах кадры всё равно синхронизируются с дисплеем и остаются около 60/90/120 FPS. Само по себе это не ошибка видеокарты.

Весь тест ограничен 30 секундами на GPU-фазу; при незавершении сохраняется частичный отчёт и причина. Для отправки нажми **«Копировать отчёт»**, вставь сюда в ChatGPT. Данные не отправляются автоматически, архивы Skyrim не изменяются.

Android `versionCode 39`, `versionName 2.16.0`. Прежние идентификатор приложения и сертификат сохранены — APK устанавливается **поверх v2.15**.

Ограничения: измеряются реальные кадры текущего тестового NIF через Vulkan, но это пока не бенчмарк игры SkyrimSE.exe. Проверка на реальном телефоне необходима один раз после установки; серверные CI-тесты покрывают логику фаз, компиляцию и подпись APK, без эмулятора.
