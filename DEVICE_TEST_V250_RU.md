# Тестирование Skyrim SE Mobile v2.50

Установи APK v2.50 **поверх** v2.49 с GitHub Releases → Assets, без удаления.

Открой «Ресурсы Skyrim SE» и дождись автоматического завершения 3 этапов FPS. Автотест должен снова использовать модель `WRDrawBridge01.nif` с 17 BSTriShape, 5879 треугольниками и пятью DDS.

В новом отчёте найди `SSE vertex RGBA`: для исходного фрагмента v2.49 ожидается **4061 треугольник**, если дескриптор и RGBA в телефоне подтвердятся. Основные 1718 треугольников по-прежнему должны использовать настоящие diffuse DDS, оставшиеся 100 треугольников без UV и без RGBA могут оставаться нейтральными.

**Главная проверка** — приложи новый скриншот 3D-моста. Если он по-прежнему однотонный, цвета вершин могут нести однотонные значения или может отсутствовать игровая настройка материалов: не надо выдавать это за доказанную правильную графику. Приложи также конец отчёта со строкой `SSE vertex RGBA`, предупреждениями и PixelCopy. На Android можно проверить повторно без удаления приложения.

Технические пределы сохранены: до 30 тысяч треугольников, до 8 моделей, ограниченная выборка ESM/REFR, 5/5 DDS и без изменения оригиналов Skyrim. Никакая часть этой версии не является полноценным SkyrimSE.exe или миром с ландшафтом/NPC.
