# Skyrim SE Mobile v2.51 — контрольная база

Исходный коммит: `129989842f073931aec0babca0ac89875376111a` (`main`).

Эта ветка создана независимо от `dev/v2.52-render-validation`. Изменения v2.52 не переносятся автоматически.

## Обязательные этапы перед выпуском

1. Запустить исходные контракты Python из `.github/workflows/android-quality-gates.yml` и чистую JVM-регрессию `bash mobile/ci/run_jvm_suite.sh` после разрешения зависимости LZ4.
2. Проверить компиляцию SPIR-V и `spirv-val` с помощью `mobile/ci/setup_android_build.sh`.
3. Собрать `:app:assembleDebug` и выполнить `mobile/ci/verify_apk.sh`.
4. Убедиться в `arm64-v8a`, сохранении идентификатора пакета и сертификата для обновления поверх установленной v2.51.
5. На физическом Android проверить NIF/DDS, белые поверхности, освещение, Vulkan fallback и повторное открытие сцены.

Важно: успешная сборка и работа игры не считаются подтверждёнными, пока соответствующие этапы не завершились успешно. Приложение — диагностический просмотрщик ресурсов Skyrim SE, не полный порт игрового движка.
