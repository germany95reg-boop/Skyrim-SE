# Тестирование v2.46 на Android (Skyrim SE Mobile)

1. Установи APK v2.46 поверх v2.45 (без удаления).
2. Открой «Ресурсы Skyrim SE». Автопоиск должен запуститься, используя сохранённый доступ к Skyrim/Data, и открыть реальную NIF-сцену.
3. Убедись, что сцена не нарисована ребром; в автоматическом тесте камера теперь не вращается и выбирается ракурс с крупной проекцией.
4. После автозакрытия Vulkan просмотри отчёт: `BSA`, `NIF`, `DDS декодировано/найдено`, список причин отказа (в том числе BC7 режимы вне 5/6), процент текстурированных треугольников, предупреждения о небольшом кадре.
5. Не сравнивай значение GPU PASS 7 со «вся локация готова». Если снова показан только мост, должен быть WARN про **1 REFR**, даже если Vulkan запускается и даёт FPS.

Пришли скриншот рендера и конец текстового отчёта, начиная с `DDS:`. По нему можно определить, какие BC7 режимы ещё нужно добавить, или являются ли причиной лимиты памяти/архивы.

Данные игры используются только на чтение. Приложение по-прежнему не загружает игровой ландшафт, NPC, объекты вне выбранного фрагмента или оригинальные игровые шейдеры.
