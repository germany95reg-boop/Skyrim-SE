# Skyrim SE Mobile Launcher

Отдельный Android ARM64-проект **Skyrim Special Edition**. Никакого TamrielVoice. Адаптивный лаунчер «Моды» / «Настройки», пока **без игрового движка Skyrim SE**.

## Текущий статус

- **v0.6 — подтверждено на реальном Samsung ARM64/Adreno 840:** по отчёту пользователя тестовая OBJ-пирамида отображалась, вращение и сенсорное управление работали. Диагностика сообщала о 230 кадрах, последнем FPS 120 и 8 рёбрах модели. Это не замер средней производительности Skyrim.
- **v0.7 — APK успешно собран в GitHub Actions:** [успешная сборка #41937582565](https://github.com/germany95reg-boop/Skyrim-SE/actions/runs/41937582565), артефакт `Skyrim-SE-Vulkan-3D-v0.7-APK`. На реальном устройстве инспектор ресурсов **ещё не проверен**.

## v0.7: инспектор игровых ресурсов (только чтение)

Новый экран **Настройки → Ресурсы Skyrim SE · BSA / NIF (чтение)**:

- **Проверить папку игры / Data:** использует ранее выбранный каталог или отдельно выбранную папку Data. Считает BSA, BA2, ESM/ESP/ESL и каталогов в корне Data (не сканирует вложенные папки).
- **Выбрать папку Data:** выбор через стандартный Android Storage Access Framework, разрешение только на чтение.
- **Проверить файл BSA / NIF:** можно выбрать файл отдельно; считываются лишь первые 256 байт.
- BSA — распознавание версии по бинарной сигнатуре (`BSA\\0`, версии 103/104/105; Skyrim SE обычно 105), количество папок и файлов.
- NIF — строка заголовка NetImmerse/Gamebryo и версия формата; **геометрия NIF не декодируется и не отображается**.
- BA2 — только распознавание отдельного типа по `BTDX`.
- **Скопировать отчёт:** вывод результата диагностики. Отчёт также включается в диагностику лаунчера.

Никакой распаковки BSA, копирования игровых ассетов, подключения SkyrimSE.exe или установки модов не выполняется. Исполнение движка, совместимость NIF и поддержка SKSE64 не реализованы.

## Проверка на Android

1. Установи APK из зелёной сборки GitHub Actions v0.7, сохранив нужные данные приложения при возможной переустановке.
2. Открой **Настройки → Ресурсы Skyrim SE · BSA / NIF (чтение)**.
3. Выбери папку Data игры (либо корень игры, содержащий Data).
4. Нажми **Проверить папку игры / Data** и скопируй отчёт.
5. Для первой ручной проверки файла можешь отдельно открыть `Skyrim - Meshes.bsa` в режиме чтения. Пока мы читаем только заголовок, не распаковываем ресурсы.

Ранее проверенная OBJ-пирамида и все тесты Vulkan доступны в этом же APK. В среде без доступа к реальным данным Skyrim их содержимое не проверено. Android может запрещать доступ к отдельным каталогам через SAF.
