# Skyrim SE Mobile Launcher — v1.8

Экспериментальный Android ARM64/Vulkan-лаунчер для просмотра ресурсов Skyrim SE, NIF и BSA. **Это не готовый порт игрового движка Skyrim SE**; SkyrimSE.exe, игровой мир и SKSE64 не запускаются.

### Самое важное об установке

**v1.7 → v1.8:** если Android сообщает о несовместимых подписях, потребуется **последний раз удалить старую версию перед установкой v1.8**. Без старого временного закрытого ключа невозможно безопасно обновить уже установленный APK с новой подписью. Удаление приложения может стереть настройки и ранее выданные разрешения на папку Data; запишите настройки и путь перед переходом. После установки v1.8 снова предоставьте доступ к Data, если потребуется.

**v1.8 → v1.9, v2.0 и последующие:** можно будет устанавливать новую подписанную тем же постоянным ключом APK непосредственно поверх установленной версии, без потери её данных. Критично не менять applicationId/сертификат и повышать versionCode.

Это **тестовый, незащищённый для публичного релиза ключ**, его нельзя выкладывать публично. Сейчас он находится в приватном GitHub-репозитории и использует стандартный debug-пароль. Любой, кто получит этот ключ, сможет подписать совместимое обновление. Ограничивайте доступ к репозиторию, сохраните резервную копию, не публикуйте ключ и перед публичным релизом перенесите подпись в защищённые GitHub Actions secrets/отдельное хранилище.

## Ресурсы Skyrim SE — актуальная проверка v1.7

Реальные заголовки DDS из `ccBGSSSE001-Fish.bsa` подтверждены на устройстве:

| Файл | Разрешение | Формат DDS | Mip-уровни | Размер записи |
|---|---|---|---:|---:|
| `LureArgonian.dds` | 128×256 | BC1 / DXT1 | 7 | 21976 Б |
| `LureArgonian_n.dds` | 128×256 | BC3 / DXT5 | 7 | 43824 Б |

Оба DDS находятся в BSA без сжатия на уровне архива. Файл `MarketplaceTextures.bsa` по-прежнему выдаёт предупреждение о таблице имён (2084 из заявленных 2093 байт). **DDS ещё не декодируются и не отображаются на 3D-модели**: v1.8 решает иконку и обновления, графика осталась в состоянии v1.7.

Исходники v1.8 хранятся в `.skyrimse-v18-source.tar.xz`. Постоянный тестовый сертификат хранится отдельно в закрытой `.ci/` и **не включён в публично передаваемый ZIP исходников**.

**Проверено в CI:** Java-тесты, NIF/BSA/LZ4, компиляция Vulkan, новая иконка и наличие пакета, инкремент версии, стабильный сертификат через `apksigner`. Визуальное отображение иконки и установка v1.8 на реальном телефоне ещё требуют проверки.
