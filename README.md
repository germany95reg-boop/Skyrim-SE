# Skyrim SE Mobile Launcher

Отдельный Android-проект Skyrim Special Edition с согласованным адаптивным интерфейсом «Моды» / «Настройки». **Это пока тестовый лаунчер и графический стенд, не готовый порт Skyrim SE.**

## v0.5 — Vulkan 3D, сенсорная камера

Успешная сборка: **[GitHub Actions v0.5](https://github.com/germany95reg-boop/Skyrim-SE/actions/runs/41933730426)**.

Артефакт `Skyrim-SE-Vulkan-3D-v0.5-APK` содержит `app-debug.apk`. Сборка успешно прошла Java/Gradle, NDK/C++ и компиляцию GLSL → SPIR-V; **проверка v0.5 на устройстве ещё нужна**.

В тестовом экране:
- один палец — вращение камеры;
- два пальца — приближение/отдаление;
- «Авто» — включение/отключение вращения куба;
- «FPS» — ограничение до 30, 60 либо без ограничения;
- «Сброс» — исходный вид;
- улучшен возврат в сцену после смены ориентации и сворачивания приложения;
- сохранён прежний тест Vulkan-кадра (v0.3).

**Как проверить:** Настройки → **3D-тест Vulkan · сенсорная 3D-камера**. После выхода можно скопировать диагностику из лаунчера.

## Ограничения

Нативное исполнение SkyrimSE.exe, SKSE64, моды в игре и игровой рендер не реализованы. Моды пока только импортируются/учитываются лаунчером; графические тесты не используют Skyrim SE. Отдельных Windows-слоёв совместимости не добавлено.

Исходники передаются в GitHub Actions в виде временного архива `.skyrimse-v05-source.tar.xz.b64`, распаковываются, после чего собираются Gradle.

Предыдущие версии v0.3 и v0.4 сохранены для воспроизводимости тестов.
