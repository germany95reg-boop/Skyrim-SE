# Skyrim SE Mobile Launcher

Отдельный Android-проект с адаптивными вкладками **«Моды»** и **«Настройки»**. Это пока **лаунчер + отдельный Vulkan-графический стенд**, а не готовый порт Skyrim Special Edition.

## v0.6 — OBJ → нативный Vulkan

Успешная сборка: **[GitHub Actions run #41935694479](https://github.com/germany95reg-boop/Skyrim-SE/actions/runs/41935694479)**.

Скачай артефакт **Skyrim-SE-Vulkan-3D-v0.6-APK**, распакуй и установи `app-debug.apk`. Подпись отладочной сборки может отличаться от v0.5 — Android может попросить удалить предыдущий APK после сохранения важных данных.

В `Настройки → 3D-тест Vulkan · OBJ-модели и камера`:

- **Пример: пирамида** — прочитать встроенный текстовый Wavefront OBJ и отобразить его каркас;
- **Выбрать OBJ** — открыть системный выбор документа и загрузить обычную модель формата `.obj` из хранилища Android;
- **Куб** — вернуть встроенный 3D-куб;
- **Авто**, **FPS**, **Сброс** — прежнее управление камерой.

Формат OBJ: `v` (позиции), `f` (грани) и `l` (линии), положительные и отрицательные индексы. Поддерживается только **каркасная геометрия без текстур**, не модели Skyrim `.nif`. Ограничения: файл до 4 МиБ, до 40 тыс. исходных вершин и 30 тыс. рёбер. Нативный рендерер получает координаты через Vulkan vertex buffer.

**Проверки:** чистая сборка Android/NDK, GLSL → SPIR-V, наличие библиотек и модели в APK — успешно. Парсер прошёл 7 локальных тестов. **Отрисовка OBJ на реальном телефоне ещё не подтверждена.**

> Важно: этот тест не выполняет `SkyrimSE.exe`, не загружает игровую сцену, не применяет моды к Skyrim и не поддерживает SKSE64. Вертикальная/горизонтальная компоновка лаунчера сохранена.
