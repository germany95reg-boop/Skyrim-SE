# Skyrim SE Mobile Launcher

Отдельный экспериментальный Android-лаунчер для Skyrim Special Edition. **Нативный игровой движок Skyrim SE пока не реализован**. Репозиторий не содержит игру, Windows EXE и игровые ресурсы.

## Статус: v0.4 (Vulkan 3D)

- Сохранены две адаптивные вкладки «Моды» и «Настройки» (портретный и альбомный экран, вертикальная прокрутка).
- Сохранён проверенный на Android одноцветный Vulkan-тест версии v0.3.
- Добавлен отдельный **нативный ARM64 Vulkan 3D-тест**: шейдерная отрисовка вращающегося каркаса куба с перспективой, количество кадров, FPS, ориентация Surface.
- Новая сцена работает отдельно от игры; кнопка «Играть» правильно остаётся неактивной.
- **Облачная сборка v0.4: SUCCESS**, workflow [GitHub Actions run #41932115699](https://github.com/germany95reg-boop/Skyrim-SE/actions/runs/41932115699), артефакт **Skyrim-SE-Vulkan-3D-v0.4-APK**.
- Работа сцены v0.4 на реальном устройстве ещё не проверена.

## Установка на Android

В [Actions](https://github.com/germany95reg-boop/Skyrim-SE/actions) открой успешную сборку версии v0.4 и скачай артефакт `Skyrim-SE-Vulkan-3D-v0.4-APK`. Внутри — `app-debug.apk`.

После установки открой **Настройки → 3D-тест Vulkan · вращающийся куб**. Ожидается цветной вращающийся каркас куба, FPS и количество кадров. Проверяй также автоматический поворот и возврат в лаунчер.

Предыдущая версия v0.3 может быть подписана другим отладочным ключом: при ошибке Android «Приложение не установлено» предварительно сохрани нужные данные и удали старый тестовый APK.

## Как устроена сборка

- GitHub Actions использует Java 17, Android SDK/NDK, Gradle и `glslangValidator`.
- Исходники v0.4 упакованы в `.skyrimse-v04-source.tar.xz.b64`; это временная форма передачи исходников для CI.
- Шейдеры `cube.vert` и `cube.frag` собираются в SPIR-V до компиляции APK.
- Нативные библиотеки: `skyrimse_probe`, `skyrimse_renderer` (первый кадр) и `skyrimse_scene` (3D-рендер).

Планы на дальнейшие версии: стабильный жизненный цикл Vulkan, обработка устройства, загрузка безопасных тестовых моделей и изучение архитектуры портирования Skyrim SE. Поддержка SKSE64 и исполнение SkyrimSE.exe **не гарантируются**.
