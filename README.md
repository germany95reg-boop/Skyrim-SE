# Skyrim SE Mobile Launcher

Экспериментальный нативный Android ARM64/Vulkan-лаунчер для Skyrim Special Edition. Это **не порт движка Skyrim SE**: игра SkyrimSE.exe, SKSE64, игровые сценарии и текстуры не запускаются.

## Подтверждено на Samsung Android 17 / Adreno 840

- **v0.6:** пользователь подтвердил Vulkan-пирамиду, сенсорную камеру и вывод 3D-графики.
- **v0.7:** подтверждено чтение реальных папки Data и заголовков BSA 105.
- **v0.8:** индекс `ccBGSSSE001-Fish.bsa`: 110 папок, 744 файла, 231 NIF, флаги `0x83`.
- **v0.9:** чтение настоящей записи `lureargonian01.nif` из BSA (5092 байта, NIF 20.2.0.7).
- **v1.0:** реальная модель содержит 8 блоков, включая `BSTriShape` (4096 байт), Bethesda Stream 100.
- **v1.1:** **пользователь прислал скриншот настоящего NIF-каркаса в Vulkan**, `lureargonian01.nif`: 248 рёбер, 209 кадров, моментальный FPS **59,7**, разрешение **1440×2915**. Успешное отображение геометрии подтверждено визуально; это не FPS игры Skyrim.

## v1.2 — NIF: локальные преобразования и осмотр модели

**Сборка: [GitHub Actions SUCCESS — v1.2](https://github.com/germany95reg-boop/Skyrim-SE/actions/runs/42053702305)**. Скачайте артефакт `Skyrim-SE-Vulkan-3D-v1.2-APK` и извлеките `app-debug.apk`.

SHA-256 APK: `b4334cfc1e6c8a93cc408448735045f73a17e941262fb8b5852fb968c64cd521`.

### Что добавлено

- Применение **локальных** Translation / Rotation / Scale из `NiAVObject` блока `BSTriShape`, до нормализации и передачи сегментов в Vulkan.
- Проверка некорректных значений и ограничений чисел с плавающей точкой; исходный BSA не изменяется.
- В отчёте: исходные размеры по осям XYZ, размеры после локального преобразования, масштаб и смещение модели.
- На экране Vulkan: компактные габариты NIF и кнопки **«Спереди», «Сбоку», «Сверху»**. Выбор фиксированного ракурса выключает автовращение; обычное управление одним/двумя пальцами и FPS сохранены.
- Старые тесты Vulkan-кадра, OBJ-пирамиды, каталогов BSA и чтения NIF остались доступны.

### Проверка на телефоне

1. Установить APK v1.2. При конфликте подписи отладочных APK сначала сохранить нужные данные предыдущей версии.
2. Настройки → **Ресурсы Skyrim SE** → **Каталог BSA v105** → `ccBGSSSE001-Fish.bsa`.
3. Найти `lureargonian01.nif` → **«Показать BSTriShape в Vulkan · v1.2»**.
4. Сравнить форму с предыдущим снимком v1.1, переключить три ракурса, проверить жесты и FPS.
5. Вернуться в инспектор и скопировать отчёт с габаритами модели.

**CI:** компиляция Android/NDK/GLSL и регрессионные тесты BSA/LZ4/NIF прошли; **45 проверок нового декодера** на синтетической геометрии. Воспроизведение v1.2 с конкретным настоящим NIF на устройстве **пока не подтверждено**.

### Ограничения

Только статическая каркасная геометрия поддерживаемого `BSTriShape`; преобразования **родительских узлов scene graph пока не применяются**. Нет текстур и материалов Skyrim, скелетов и анимаций, Havok, загрузки игровых локаций и исполнения SkyrimSE.exe. Эти функции требуют отдельной полноценной реализации.

Сборочные исходники v1.2 временно хранятся в `.skyrimse-v12-source.tar.xz.b64`. Проект ведётся только в репозитории **Skyrim-SE**.
