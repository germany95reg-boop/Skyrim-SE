# Skyrim SE Mobile Launcher — v1.7

Экспериментальное Android ARM64-приложение для просмотра ресурсов Skyrim Special Edition и отдельного Vulkan-рендера NIF. **Это ещё не порт игрового движка SkyrimSE.exe**; игровой мир, SKSE64 и настоящие материалы Skyrim не запускаются.

### Что умеет v1.7

- Новый экранный шаг **«Заголовки найденных DDS · v1.7»** после поиска DDS в Data.
- Читает выбранные DDS-записи из BSA по ранее установленным точным смещениям.
- Для несжатых записей читает **только первые 128/148 байт**, не трогая пиксельную часть. Для BSA-сжатых LZ4 — ограниченное потоковое чтение, с проверкой суммарного декодированного размера; в память сохраняется только заголовок.
- Определяет размеры изображения, число mip-уровней, FourCC, DXGI/DX10 и семейства GPU-блочного сжатия BC1/BC2/BC3/BC4/BC5/BC6H/BC7, где формат распознан.
- Различает **сжатие в BSA** (в отчёте v1.6 нет) и **внутренний BCn-формат DDS**.
- Безопасные пределы: 8 МиБ размера записи BSA, 16 МиБ распакованных данных, до 32 уникальных целевых DDS и 64 найденных записей.
- Ошибка `MarketplaceTextures.bsa` диагностируется с указанием фактической и заявленной длины таблицы имён. Парсер не ослабляет проверку формата.
- Vulkan каркас/поверхность, авто-вписывание, OBJ и остальные функции сохранены.

### Проверка на Android

1. Установить APK v1.7 (при несовместимой подписи отладочных сборок сохранить нужные данные перед удалением старой версии).
2. **Настройки → Ресурсы Skyrim SE → Каталог BSA v105**; открыть `ccBGSSSE001-Fish.bsa` и найти `lureargonian01.nif`.
3. Нажать **«Пути текстур NIF · v1.7»** → **«Найти DDS в папке Data · v1.7»**, выбрать каталог `Data`.
4. После появления совпадений нажать **«Заголовки найденных DDS · v1.7»**.
5. Скопировать отчёт, в котором должны появиться форматы и размеры обеих DDS.

**GitHub CI:** успешно прошли тесты каталогов BSA, заголовков NIF, NIF материалов, поверхности BSTriShape, камеры, DX10/BCn и интеграции BSA DDS с LZ4. APK проверен на наличие `DdsHeaderInspector`, `BsaDdsInspector`, трёх ARM64-библиотек и трёх SPIR-V шейдеров. Реальный DDS-инспектор на устройстве ещё не проверялся.

**Ограничение:** в v1.7 не распаковываются пиксели DDS и текстуры пока не загружаются в Vulkan; GPU-возможности форматов и UV-координаты модели ещё не проверены. Данные оригинальной Skyrim SE не изменяются.

Исходники собранной версии доступны в `.skyrimse-v17-source.tar.xz`.
