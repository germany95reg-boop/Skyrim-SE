# Skyrim SE Mobile Launcher

Экспериментальный Android ARM64/Vulkan-лаунчер. **Это ещё не рабочий порт игрового движка Skyrim Special Edition.** SkyrimSE.exe и SKSE64 не исполняются.

## Подтверждённые результаты на Samsung Android 17 / Adreno 840

- v0.6 — реальная Vulkan-отрисовка OBJ-пирамиды, жесты камеры.
- v0.7 — чтение каталога Data, заголовков настоящих BSA 105.
- v0.8 — каталог `ccBGSSSE001-Fish.bsa`: 110 папок, 744 файла, 231 NIF.
- v0.9 — чтение единственного реального `lureargonian01.nif` (5092 байта, NIF 20.2.0.7), без изменения исходного BSA.
- v1.0 — успешно прочитаны 8 NIF-блоков, в том числе `BSTriShape` 4096 байт.
- v1.1 — пользователь прислал скриншот настоящего NIF-каркаса в Vulkan: 248 рёбер, FPS 59,7.
- v1.2 — пользователь подтвердил отображение той же модели, FPS 120 без лимита, габариты XYZ 3,27×7,74×1,26. На экране модель была частично перекрыта панелью управления.

### Что изменено

- Адаптивная фокусировка на модели в **видимой области между заголовком и нижней панелью**, а не в физическом центре всей поверхности Vulkan.
- Новая кнопка **«Вписать»** и автоподбор камеры с максимальной дистанцией до 40.
- Режимы «Сброс», «Спереди / Сбоку / Сверху» пересчитывают расстояние до модели.
- Поворот устройства и изменение высоты панели обновляют вертикальный сдвиг проекции.
- После ручного масштабирования управление остаётся ручным до повторного «Вписать».
- Прежние тесты Vulkan/OBJ, каталог BSA 105, чтение LZ4/NIF, ограниченный каркасный декодер BSTriShape сохранены.

### Проверки сборки

GitHub Actions подтвердил: Android Java/NDK, GLSL → SPIR-V, проверки каталога BSA, чтения NIF/LZ4, декодера BSTriShape, управления камерой и расчёта видимого кадра. Отдельно были выполнены 13 тестов `SceneFramingTest`.

Первый запуск CI выявил конфликт локального имени `top` в Java-обработчике компоновки. Проблема исправлена; последующий запуск завершился **SUCCESS**. Готовый APK содержит три ARM64-библиотеки, SPIR-V-шейдеры и DEX.

**На реальном телефоне кадрирование v1.3 ещё нужно проверить визуально.** Сборка APK не является подтверждением отсутствия наложения модели на UI.

### Проверка на телефоне

1. Установить v1.3. При конфликте debug-подписей сохранить нужные данные старого APK перед удалением.
2. Настройки → Ресурсы Skyrim SE → Каталог BSA v105; открыть `ccBGSSSE001-Fish.bsa`.
3. Найти `lureargonian01.nif` → «Показать BSTriShape в Vulkan».
4. Выбрать «Спереди» и нажать **«Вписать»**; проверить, что вся модель полностью видна между панелями.
5. Переключить «Сбоку», «Сверху», жесты масштабирования и ориентацию телефона. Прислать скриншот и FPS.

### Реальные ограничения

Только выборочные статические BSTriShape и каркасный рендер. Не реализованы текстуры, материалы, иерархия родительских NIF-преобразований, анимация, игровой мир и нативное исполнение SkyrimSE.exe.

Исходники v1.3: `.skyrimse-v13-source.tar.xz`, распаковываемые CI в `SkyrimSEMobileLauncher_v1.3`. Все файлы игры читаются без изменения.
