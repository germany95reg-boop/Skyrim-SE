# Skyrim SE Mobile v2.36 — автоматическая проверка найденных NIF

## Основание изменения

Пользователь трижды прислал отчёт v2.35 после поиска по 23 BSA, без секции «Проверка содержимого найденных NIF». Технически проверка содержимого была доступна отдельной кнопкой, но необходимость второго нажатия мешала завершить рабочий процесс.

Сведения из реальных отчётов:
- Skyrim.esm, WRLD: 997 заголовков, 8 из 8 NAME+DATA, 5 из 6 базовых FormID.
- Из 23 архивов 23 каталога прочитано, 3 из 4 моделей найдены в Skyrim - Meshes0.bsa.
- Единственный частичный индекс — Skyrim - Voices_ru0.bsa.

## Изменено в v2.36

- После кнопки «Найти MODL во всех BSA папки Data» приложение **автоматически** переходит к проверке содержимого найденных NIF (до 3). Никаких дополнительных нажатий не требуется.
- Во время чтения выводится «Проверка содержимого NIF: 1 / 3...»; по завершении полный отчёт включает «Проверка содержимого найденных NIF · только чтение».
- Возможность вручную повторить проверку оставлена.
- Новые проверки используют прежний BsaEntryInspector: LZ4 Frame, ≤8 МиБ входных, ≤16 МиБ выходных данных на NIF; содержимое файла не сохраняется.
- Устаревшие потоки проверки не должны перезаписывать новые результаты после смены ESM, повторного запуска или закрытия окна.

## Как проверить

1. Установить v2.36.0 (versionCode 59) поверх v2.35.0, не удаляя приложение.
2. «Настройки → Ресурсы Skyrim SE → Записи WRLD» → Skyrim.esm.
3. «Найти MODL во всех BSA папки Data» → после поиска без дополнительных действий появится секция проверки реальных NIF.
4. Дождаться окончания обработки трёх моделей и скопировать **полный отчёт**. Если найдена ошибка распаковки, она тоже будет показана.
5. Передать отчёт для дальнейшего декодирования геометрии NIF.

Не является загрузкой игрового мира, NPC или SkyrimSE.exe. Продолжительный FPS-тест не включён.
