# Skyrim Cheat Keyboard 0.2
Standalone Android IME which sends Skyrim 2011 console commands through Android's InputConnection, leaving the original Skyrim APK and its signature untouched.

Install standalone APK; enable and select the keyboard in Android Settings; open the in-game console (~); request the soft keyboard and select a cheat. Switch KEYS/TEXT in the keyboard if necessary. This mechanism requires the port to expose an IME-compatible text input; compatibility on physical device is unverified.

Includes god mode toggle (tgm), move speed presets, carry weight +/−10000, shout cooldown presets, gold, lockpicks, dragon souls, unlock, psb (double confirmation), eight skill boosts, and Enter/Delete/~ keys.

The keyboard cannot inspect the actual game state. Skill changes, spells and resource changes cannot be automatically undone. No network or storage permissions, no root. Use only for Skyrim and revert to your standard keyboard for sensitive typing.
