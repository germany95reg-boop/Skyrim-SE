# Skyrim SE Mobile v2.35 — чтение обнаруженных NIF из BSA

Аппаратная проверка v2.34: 23/23 BSA перечислено, 3/4 путей MODL найдены в Skyrim - Meshes0.bsa, 1 архив имел неполный индекс. Найдены: MGEyeBarrierLarge.nif, StockadeBarricade01.nif, MarkerX.nif. Marker_Horse.nif не подтверждён из-за неполного покрытия.

## Новое

- После «Найти MODL во всех BSA папки Data» можно нажать **«Проверить содержимое найденных NIF»**.
- Программа повторно открывает не более **трёх** архивных записей, к которым привязаны обнаруженные пути MODL, и распаковывает NIF **только в памяти**, переиспользуя уже отлаженный `BsaEntryInspector`.
- Для BSA v105 доступны несжатые записи и LZ4 Frame, с защитой: до 8 МиБ сжатых данных и 16 МиБ распакованных.
- Отчёт показывает архив, путь, смещение, размеры и распознанный заголовок NIF либо ошибку.
- Никакой выгрузки файлов на устройство, исправления BSA, загрузки текстур или размещения сцены в Vulkan нет.
- Дополнительно перечисляются названия архивов с неполной BSA-индексацией.

## Проверка на телефоне

1. Установить v2.35.0 (versionCode 58) поверх v2.34.0.
2. Открыть `Настройки → Ресурсы Skyrim SE → Записи WRLD` и выбрать `Skyrim.esm`.
3. Нажать **«Найти MODL во всех BSA папки Data»**. При необходимости выбрать и разрешить папку Data.
4. После завершения поиска нажать **«Проверить содержимое найденных NIF»**, скопировать отчёт и прислать для следующей стадии.
5. Убедиться, что приложение не зависает и исходные файлы остались неизменными.

Это не игровой движок и не полный 3D-мир; следующий этап — декодирование геометрии и корректное размещение найденных NIF по DATA XYZ.
