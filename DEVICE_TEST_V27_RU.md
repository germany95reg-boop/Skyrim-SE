# Skyrim SE Mobile v2.7 — проверка внутри приложения

Установка APK не описывается.

1. Открой **Настройки → Ресурсы Skyrim SE · BSA / NIF (чтение) → Каталог BSA v105 · выбор и проверка NIF**.
2. Нажми **«Выбрать архив BSA»** и укажи `ccBGSSSE001-Fish.bsa`. В поле поиска введи `lureargonian01.nif`.
3. Нажми **«Части NIF · выбрать BSTriShape · v2.7»**. Должна появиться одна доступная часть #5. Закрой окно списка, не открывая её.
4. Найди **новую кнопку «Показать все части NIF в Vulkan · v2.7»** и нажми. Для рыбной приманки из Fish.bsa она соберёт одну часть; откроется 3D-просмотрщик с заголовком **Vulkan 3D · v2.7**.
5. Нажми **«Поверхность»**. В этом режиме модель однотонная, потому что **новая составная сцена пока без DDS**, даже если исходная модель имеет текстуру. Кнопки DDS и «Нормали» здесь неактивны — это ожидаемо.
6. Нажми **«Спереди» → «Сбоку» → «Крупнее» → «Вписать»**. Проверь, не пропадает ли объект и остаётся ли FPS стабильным.
7. Нажми **«← Назад»**, вернись в каталог и **проверь старый режим с текстурами**: «Пути текстур NIF · v2.7» → «Найти DDS в папке Data · v2.7» → выбери всю папку Data → «Показать NIF с DDS в Vulkan · v2.7». Здесь DDS и карта нормалей снова должны работать.
8. Для проверки главной функции v2.7 выбери **другой NIF-файл из своих игровых BSA**, где список «Части NIF» содержит две или более поддерживаемые BSTriShape. Сначала проверь количество частей по новой кнопке. Затем нажми **«Показать все части NIF в Vulkan»**. Все поддерживаемые части должны появиться **вместе в одном кадре**.
9. Если для выбранного NIF приложение сообщает о лимите 30 000 рёбер или 30 000 треугольников, это защита от превышения возможностей тестового Vulkan-рендерера, а не ошибка игровых файлов.

**Что прислать:** скриншот нового совместного просмотра и текст отчёта из каталога NIF. Для модели с 2+ частями особенно важны номер каждой части, количество «пропущено», вид модели и FPS.

**Ограничение:** сложные модели с родительскими NiNode/BSFadeNode преобразованиями могут отображаться с неправильным относительным расположением. Назначения DDS отдельным частям и скелетные модели ещё не поддержаны. Игровые файлы не меняются.
